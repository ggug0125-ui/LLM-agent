# LLM AI 에이전트 개발 입문

LLM 기반 AI 에이전트 및 챗봇 개발 실습 프로젝트입니다.

## 주요 실습 내용

* LangChain 기반 챗봇 구현
* LangGraph 상태 기반 챗봇 구현
* RAG(Retrieval-Augmented Generation) 문서 검색 챗봇
* Streamlit 기반 챗봇 UI 구현
* Vision AI 이미지 분석
* 인터넷 검색 기반 AI 챗봇 구현
* PDF 문서 요약 및 분석
* 세션 메모리 기반 대화 구현
* Retriever 기반 문서 검색 시스템 구현

## 사용 기술

* Python
* OpenAI API
* LangChain
* LangGraph
* Streamlit
* ChromaDB
* PyMuPDF
* Ollama

## 프로젝트 목표

실제 데이터를 기반으로 문서 검색, 이미지 분석, 인터넷 검색, 메모리 기반 대화 기능을 구현하며 LLM AI 에이전트 개발 흐름을 학습한다.
